# Event sources

Search only public pages. Never log in, never scrape LinkedIn, never register or buy tickets.
Never propose events organised by organisations in `knowledge/job_filters.json`.

**How to use:** open the agenda pages below first (one fetch each), then use WebSearch for extra events
(e.g. "netwerkevent sport Amsterdam december 2026", "sport en maatschappij congres 2027",
"traineeship event 2027"). Only propose events whose own page you opened. When a page stops
working, move it to "Not working" with the date and record it in `LESSONS.md`.
